Política de Privacidade do BastSocial

Última atualização: 16 de novembro de 2026.

BastSocial (BAST SOCIAL PUBLISHER) é um programa de uso pessoal, instalado no computador do dono do canal Bast, que envia vídeos para o YouTube. Esta política explica quais dados o programa acessa e o que faz com eles.

Serviços de API do YouTube

O programa usa os Serviços de API do YouTube. Ao autorizá-lo, o usuário concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é descrito na Política de Privacidade do Google.

Dados acessados

  • Identificador e nome do canal do YouTube autorizado, para indicar qual conta está conectada.
  • Estado dos vídeos enviados pelo próprio programa (em processamento, processado, rejeitado).
  • Credenciais de acesso emitidas pelo Google (tokens OAuth) para enviar vídeos em nome do canal.

O programa não acessa comentários, mensagens, lista de inscritos, estatísticas nem dados de outros canais.

Como os dados são usados

Os dados são usados apenas para enviar ao YouTube os vídeos escolhidos pelo dono do canal e para confirmar que cada envio foi concluído.

Onde os dados ficam

Todos os dados ficam no computador do dono do canal. As credenciais de acesso são guardadas criptografadas pelo próprio sistema operacional. Nenhum dado é enviado a servidores do BastSocial, porque eles não existem: o programa se comunica somente com o Google.

Compartilhamento

Nenhum dado é vendido, cedido ou compartilhado com terceiros.

Cookies

O programa não usa cookies nem tecnologias de rastreamento.

Retenção e exclusão

As credenciais ficam guardadas até o dono do canal desconectar a conta no programa, o que as apaga do computador e pede a revogação ao Google. O acesso também pode ser revogado a qualquer momento na página de segurança da Conta do Google, em myaccount.google.com/permissions.
